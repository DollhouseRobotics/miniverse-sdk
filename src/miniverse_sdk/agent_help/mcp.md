# Miniverse MCP

Add `https://miniverse.bot/mcp` as a remote MCP server in your MCP client, then
complete the Miniverse OAuth login when prompted. MCP authorization is separate
from `miniverse auth login`.

Use the CLI mainly to:

- validate, inspect, and upload `.mini` bundles;
- check import status and publish ready revisions;
- create, list, and delete personal API tokens.

Use the MCP mainly to:

- search and view public Miniverses;
- view your Miniverses, revisions, import status, and diagnostics;
- add, update, remove, and reorder policy and provenance attributes, including
  project pages, GitHub repositories, authors, papers, and licenses;
- publish ready revisions;
- submit Miniverse feedback.

The MCP tools call attributes `references`. Publishing is a public action;
confirm it with the user first.
